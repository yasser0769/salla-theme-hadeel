# Input for Spec Kit Assistant — HDL-07

استخدم هذا النص عند تشغيل مرحلة **Specification** في Spec Kit Assistant إذا كانت الأداة تريد إنشاء/تحديث `spec.md`.

---
Parent roadmap: `ROADMAP.md` → `HDL-07`.
Feature: **الهيدر بأربعة تخطيطات** (Four Header Layouts).
Phase: المرحلة 1 — النواة التجارية المشتركة.
Dependencies: HDL-02, HDL-03, HDL-04, HDL-05, HDL-06.
Work classification: Existing — Audit & Polish + Build.

اكتب مواصفة وظيفية لثيم هديل على سلة. هديل ثيم واحد عام بنواة مشتركة وأربعة Presets. ترتيب القرار: زيادة التحويل، ثم سهولة التخصيص وتنوع الأشكال، ثم الجمال والحركة.

**الوصف المبسط:** نبني نواة هيدر واحدة بأربعة أشكال مختلفة: كلاسيكي، وسطي، شفاف فوق البانر، وعملي للمتاجر الكبيرة.

**القيمة:** الهيدر يغيّر شخصية المتجر ويختصر الوصول للبحث والتصنيفات والسلة دون تكرار المنطق.

**داخل النطاق:**
- أربعة تخطيطات مع نواة مشتركة للشعار والقائمة والبحث والحساب والمفضلة والسلة.
- Sticky header اختياري وسلوك تحول الهيدر الشفاف عند التمرير.
- تنظيم صف واحد أو صفين حسب التخطيط.
- ألوان قبل/بعد التمرير وشعار مناسب للخلفيات.
- سلوك جوال موحد ومناسب لكل تخطيط.
- التوافق مع الشريط الإعلاني والقوائم والبحث.

**خارج النطاق:**
- أربعة ملفات منطق مستقلة.
- نسخ هيدر Kalles حرفيًا.
- إتاحة تركيبات تجعل الأيقونات أو النص غير مقروء.

**المتطلبات التي لا يجوز إسقاطها:**
- اشتراك التخطيطات الأربعة في نفس عقود الشعار والبحث والحساب والسلة.
- عمل الهيدر الشفاف على الرئيسية فقط افتراضيًا وتحوله لخلفية مقروءة عند التمرير.
- عودة الهيدر الشفاف تلقائيًا للوضع العادي عندما لا يكون أول قسم مناسبًا.
- دعم Sticky تشغيلًا وإيقافًا دون قفزة تخطيطية.
- كون جميع الأيقونات قابلة للوصول ولها حالات focus.
- عدم تكرار JavaScript أو بيانات القائمة لكل تخطيط.
- التعامل مع شعار فاتح وداكن أو بديل موثق.
- اختبار النصوص الطويلة والقائمة المزدحمة في RTL وLTR.

اجعل المواصفة:
- مفهومة لمالك غير تقني.
- مستقلة وقابلة للاختبار.
- Mobile-first وArabic/RTL-first مع English/LTR parity.
- ملتزمة بدستور `.specify/memory/constitution.md` و`AGENTS.md`.
- تبدأ بفحص الموجود وتصنيف Existing/Build/Spike/Deferred.
- لا تختار تقنية التنفيذ؛ هذا للـPlan.
- تحتوي بوابة Figma إلزامية قبل Plan للواجهات المرئية، مع `design.md` وNode IDs وموافقة المالك.
- تشترط production build وtheme guard ومعاينة سلة الحقيقية.
- تمنع نسخ كود/أصول/هوية Kalles أو رائد.
- تمنع أرقام social proof الوهمية في الإنتاج.
- تذكر أثر الحجم والأداء والوصول كمعيار قبول.
