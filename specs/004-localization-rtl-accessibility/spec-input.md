# Input for Spec Kit Assistant — HDL-04

استخدم هذا النص عند تشغيل مرحلة **Specification** في Spec Kit Assistant إذا كانت الأداة تريد إنشاء/تحديث `spec.md`.

---
Parent roadmap: `ROADMAP.md` → `HDL-04`.
Feature: **العربية والإنجليزية وRTL/LTR وإمكانية الوصول** (Localization, RTL/LTR Parity, and Accessibility).
Phase: المرحلة 0 — الأساس.
Dependencies: HDL-01, HDL-02.
Work classification: Existing — Audit & Polish.

اكتب مواصفة وظيفية لثيم هديل على سلة. هديل ثيم واحد عام بنواة مشتركة وأربعة Presets. ترتيب القرار: زيادة التحويل، ثم سهولة التخصيص وتنوع الأشكال، ثم الجمال والحركة.

**الوصف المبسط:** نجعل العربية والجوال نقطة البداية، مع إنجليزية LTR كاملة، ونضمن أن التنقل والقراءة والأزرار تعمل للجميع.

**القيمة:** يمنع الأخطاء الشائعة في الثيمات العربية ويرفع جودة السوق والثقة وسهولة الاستخدام.

**داخل النطاق:**
- مراجعة كل النصوص وترحيل الثابت منها إلى ملفات الترجمة.
- قواعد اتجاه الأيقونات والـDrawers والسلايدر والقوائم.
- Typography آمنة للعربية واستخدام اختيار خط سلة.
- دعم لوحة المفاتيح والتركيز والـARIA والتباين.
- اختبار النصوص الطويلة والأسعار والعملات والحالات الفارغة.
- مصفوفة اختبار عربية/إنجليزية على الجوال والكمبيوتر.

**خارج النطاق:**
- ترجمات آلية لمحتوى التاجر.
- إضافة خطوط خارجية غير مراجعة أو تضمين ملفات خطوط ثقيلة.
- إعادة تصميم كل واجهة داخل هذه المواصفة.

**المتطلبات التي لا يجوز إسقاطها:**
- عدم وجود نص عميل ثابت خارج ملفات الترجمة إلا لسبب موثق.
- اعتماد الاتجاه واللغة على Runtime سلة لا على كشف مخصص.
- انعكاس الأيقونات الاتجاهية فقط، وبقاء غير الاتجاهية كما هي.
- كون ترتيب Tab وFocus منطقيًا في RTL وLTR.
- امتلاك العناصر التفاعلية أسماء وصول واضحة وحالات focus مرئية.
- عدم استخدام Letter Spacing كتحكم افتراضي للنص العربي.
- اختبار أطول عناوين متوقعة وأسماء منتجات وخيارات بدون قص يضر المعنى.
- تحقيق الصفحات الأساسية بوابة إمكانية الوصول المحددة في الدستور.

اجعل المواصفة:
- مفهومة لمالك غير تقني.
- مستقلة وقابلة للاختبار.
- Mobile-first وArabic/RTL-first مع English/LTR parity.
- ملتزمة بدستور `.specify/memory/constitution.md` و`AGENTS.md`.
- تبدأ بفحص الموجود وتصنيف Existing/Build/Spike/Deferred.
- لا تختار تقنية التنفيذ؛ هذا للـPlan.
- تحتوي بوابة Figma إلزامية قبل Plan للواجهات المرئية، مع `design.md` وNode IDs وموافقة المالك.
- تشترط production build وtheme guard ومعاينة سلة الحقيقية.
- تمنع نسخ كود/أصول/هوية Kalles أو رائد.
- تمنع أرقام social proof الوهمية في الإنتاج.
- تذكر أثر الحجم والأداء والوصول كمعيار قبول.
